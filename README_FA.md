# بورس برنج عباس‌زاده — نسخه اولیه ۰.۱

این بسته یک نمونه اولیه وب/PWA واکنش‌گراست و روی مرورگر اندروید و ویندوز اجرا می‌شود.

## اجرای سریع
1. ZIP را استخراج کنید.
2. فایل `index.html` را با Chrome یا Edge باز کنید.
3. ورود اولیه نمایشی: `admin` / `admin123`
4. برای افزودن کاربر، وارد بخش «کاربران» شوید.

## امکانات موجود در نمونه
- داشبورد
- ثبت کالا و موجودی
- ثبت مشتری
- ساخت فاکتور ساده، محاسبه جمع و چاپ مرورگر
- ساخت کاربران با نقش‌های اولیه
- درخواست ورود کاربران غیرمدیر و تأیید از پنل مدیر
- خروجی و بازیابی JSON

## محدودیت‌های مهم — پیش از استفاده واقعی
این نسخه **دموی محلی** است، نه سامانه عملیاتی امن:
- اطلاعات در `localStorage` همان مرورگر/دستگاه ذخیره می‌شوند؛ همگام‌سازی چنددستگاهی/شبکه‌ای ندارد.
- تأیید ورود در همین مرورگر پیاده‌سازی نمایشی است. برای امنیت واقعی باید سرور، پایگاه داده، احراز هویت امن، نشست‌های قابل ابطال و اعلان آنلاین مدیر ساخته شود.
- رمزها در این نمونه به‌صورت ساده ذخیره می‌شوند؛ برای تولید واقعی باید هش امن سمت سرور پیاده شود.
- پیامک واقعی ارسال نمی‌شود. اتصال پنل پیامکی به API و سیم‌کارت به ماژول/سرویس محلی سازگار و مجوزها نیاز دارد.
- اتصال ترازو به مدل، پروتکل و پورت دقیق آن وابسته است. بارکدخوان USB که مانند صفحه‌کلید عمل کند در دسکتاپ قابل استفاده است.
- چاپ از قابلیت چاپ مرورگر استفاده می‌کند؛ چاپ حرارتی مستقیم و قالب‌بندی اختصاصی نیازمند پیاده‌سازی دستگاهی است.
- خروجی APK و EXE در این بسته ساخته نشده است. برای APK باید پوسته اندروید/فرایند build و امضای اپ؛ برای EXE بسته‌بندی دسکتاپ و نصب‌کننده ساخته و آزمایش شود.

## مسیر پیشنهادی تولید
۱. انتخاب معماری سرور و پایگاه داده مرکزی برای ویندوز و اندروید.
۲. پیاده‌سازی احراز هویت و تأیید ورود آنلاین فقط توسط مدیر اصلی.
۳. تکمیل خرید، فروش، برگشت، بدهکار/بستانکار، هزینه‌ها و گزارش‌ها.
۴. اتصال مدل واقعی ترازو، چاپگر و سرویس پیامک.
۵. ساخت و آزمایش APK و نصب‌کننده ویندوز.
